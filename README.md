# ЛР №1 — Методы оптимизации, вариант 19

**Федоровская Е. С., Б24-517**

## Что реализовано

- вариант вычислен по формуле из ТЗ: `V = 19`, `seed = 10125`;
- непрерывная усреднённая LP-модель минимизации отходов при резке труб;
- 5 типов труб-заготовок и 6 заказов;
- решение через HiGHS (`scipy.optimize.linprog`, `highs-ds`);
- независимая проверка решения отдельным NumPy-кодом без объекта солвера;
- базовый, дефицитный и стрессовый сценарии;
- теневые цены активных ограничений и проверка прогноза на дефицитном сценарии;
- дополнительное задание: сравнение HiGHS dual simplex (`highs-ds`) и interior point (`highs-ipm`) по времени и итерациям на 10 задачах растущего размера;
- CSV-таблицы, краткие логи сценариев, полный диагностический лог HiGHS для базового сценария, графики и отчёт.

## Модель

`x[i,j] >= 0` — среднее число заготовок типа `i`, направленных на заказ `j`.

Из длины заготовки, длины детали, ширины пропила 0.02 м и обязательной торцовки 0.05 м заранее вычисляются:

- `k[i,j]` — число деталей заказа `j` из одной заготовки `i`;
- `w[i,j]` — отход, м на одну заготовку.

Цель:

```text
min sum(i,j) w[i,j] * x[i,j]
```

Ограничения:

```text
sum(i) k[i,j] * x[i,j] >= demand[j]     для каждого заказа j
sum(j) x[i,j] <= stock[i]               для каждого типа заготовки i
x[i,j] >= 0
```

Дробные `x[i,j]` — осознанное учебное упрощение: это усреднение по серии однотипных плановых периодов. Для единичного реального раскроя нужна целочисленная модель с паттернами.

## Установка

Рекомендуется Python 3.12+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск одной командой

```bash
python main.py
```

При каждом запуске входные данные заново воспроизводятся из `seed=10125`, после чего формируются все результаты.

## Структура

```text
data/                   входные CSV + metadata.json
src/data.py             генерация/загрузка данных
src/model.py            построение LP и вызов HiGHS
src/verify.py           независимая NumPy-проверка
src/benchmark.py        дополнительное задание
src/plots.py            графики
results/                решения, проверки, сценарии, логи HiGHS, графики
report.tex              исходник отчёта LaTeX
report.pdf              оформленный отчёт для сдачи
requirements.txt        фиксированные версии
```

## Основной результат текущего запуска

Числа приведены в `report.pdf` и `results/run_info.json`. Для проверки после запуска сравнивайте `results/base_solution.csv` и `results/verification_base.json`.

Полный диагностический вывод HiGHS для базового сценария сохраняется в `results/solver_base_full.log`; краткие сводки трёх сценариев — в `solver_base.log`, `solver_deficit.log`, `solver_stress.log`. Если независимая проверка любого сценария не проходит, `main.py` завершает работу с ошибкой.
